# Projeto-DEAC

App de sistema de reservas (P02). Permite ao utilizador pesquisar hotéis,
introduzir os dados pessoais e de pagamento e confirmar a reserva.



```
Projeto-DEAC/
├── index.html           # Passo 1 — Hotel Selection
├── details.html         # Passo 2 — Your Details (formulário)
├── confirmation.html    # Passo 3 — Confirmation
├── reservar.php         # Recebe o POST do formulário
├── styles/styles.css    # Folha de estilos partilhada
├── images/              # Imagens do site
└── db/reservas.json     # Reservas guardadas (criado automaticamente)
```

## Como executar

Precisa de PHP instalado. Na pasta do projeto:

```
php -S localhost:8000
```

Depois abre <http://localhost:8000>.
